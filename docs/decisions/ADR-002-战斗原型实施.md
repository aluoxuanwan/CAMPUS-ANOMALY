# ADR-002：战斗原型实施

日期：2026-10-08。状态：已实施原型，正式产品路线仍待试玩验证。

## 背景

用户在调研完成后要求继续并进行下一步。本轮根据 ADR-001 的建议开始本地可玩原型，目标是验证移动、瞄准、攻击、冲刺、敌人、铃声、奖励和重玩。

## 选择

- 使用工作区已有 Godot 4.7.2 与 GDScript，实现 Windows 单机。
- 接手并修复已有原型，改动前保存源码快照。
- 使用人工布局模板和带种子的房间图，走过六节课程后进入结算。
- 使用程序图形与合成声音验证反馈，暂不采购正式素材或调用付费生图。
- 构建 PCK，并复用已有 Godot 编辑器二进制提供独立试玩入口。

## 范围变化

相比调研的最小原型，增加一把直尺近战武器，便于验证扇形和遮挡判定。当前四个技能固定可用，社团点数仅存储，解锁系统延后。课程奖励加权、剧情、触屏及发行平台接入尚未实施。

原型不要求具备商业 Demo 的美术与内容完成度。实际试玩是决定是否继续投入正式动画、扩充内容和移动平台的下一道门槛。

## 成本与包体

本轮新增付费素材及生成服务现金支出为 0。未计人工、设备购置、耗电及既有订阅。正式预算沿用研究模型，待获得实际素材报价和工作量记录后修订。

当前资源包约 223 KiB，随包引擎约 172.5 MiB。该体积包含编辑器功能，正式运行模板的实际体积仍需导出测量。不能用当前包体外推完整游戏或 iOS 安装大小。

## 后续决策条件

1. 人工试玩是否认可三把武器的差异、冲刺时机和敌人提示。
2. 铃声是否带来可读、可选择的战术变化。
3. 选取一种正式美术风格，制作一个角色和一间房的完整素材样本。
4. 在低端硬件及目标移动设备上测量帧时间、内存、包体与温度。
