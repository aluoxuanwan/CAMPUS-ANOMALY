# 校园异常：战斗原型试玩说明

更新日期：2026-10-08。版本：0.1.0。当前为 Windows 单机战斗原型。

## 启动

在工作区双击 [试玩校园异常.cmd](../../试玩校园异常.cmd)。也可以进入 [便携目录](../../output/windows/)，双击 `CampusPrototype.exe`。

保留同目录的 `CampusPrototype.pck`。便携版本不需要安装 Godot，也不依赖源码目录。第一次启动可能需要等待图形驱动初始化。

开始页点击“开始课外行动”，或按 Enter。点击窗口右上角关闭按钮退出。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD 或方向键 |
| 瞄准 / 攻击 | 鼠标移动 / 按住左键 |
| 冲刺 | 空格，有独立冷却和短暂无敌 |
| 切换武器 | Q，依次为粉笔、篮球、直尺 |
| 手动装填 | R，仅粉笔消耗弹药，打空后自动装填 |
| 体育回旋 | 1，旋转打击并尝试冲刺 |
| 临时炮台 | 2，攻击视线内的敌人 |
| 戏剧诱饵 | 3，吸引敌人，能够被击破 |
| 摄影闪光 | 4，伤害与短暂眩晕，墙和课桌阻挡效果 |
| 暂停 / 继续 | Esc，暂停页可调整音量和震屏 |
| 调试信息 | F3 |
| 结算后重开 | Enter 或点击“再次挑战” |

## 一局怎么玩

1. 清理教学楼入口的异常文具。
2. 战后从三个奖励中选一个，再安排下一节课。每局有一次重抽机会。
3. 开场后有两条课程路线，每条经过三间战斗房，随后汇合到精英房。
4. 第六节挑战试卷巨像。Boss 循环使用直线试卷、扇形组合和铃声转换。
5. 失败与通关都会保存社团点数和记录。原型中的社团点数仅用于保存进度，尚未提供解锁商店。

普通房间每 17 秒切换课堂和课间。切换前 3 秒出现地面边缘提示；部分课桌暂时移开，课间敌人加速。避开敌人的红色前摇外圈，利用墙、课桌、侧移和冲刺躲开攻击。

粉笔可以反弹并破坏课桌。篮球去程与回程各可命中同一敌人一次。直尺使用扇形近战，墙和课桌会阻挡判定。切换武器保留弹匣。

## 保存位置

Windows 常规试玩存档位于 `%APPDATA%/Godot/app_userdata/校园异常 战斗原型/save_v1.json`，旁边有一个有效备份。存档保存设置、社团点数、历史记录和标签，当前局不会中途续存。

自动检查和截图使用同目录内的 `qa/` 子目录。测试不写入常规试玩存档。

## 当前内容与限制

| 内容 | 当前状态 |
|---|---|
| 武器 | 3 把可用 |
| 社团技能 | 4 项可用；另有 2 项定义供后续扩展 |
| 敌人 | 6 类普通敌人、精英倍率、1 个 Boss |
| 地图 | 8 个布局模板，每局走过 6 个节点 |
| 成长 | 12 项定义，战后提供 11 项兼容当前技能的词条；沾墨扩散暂不进入奖励池 |
| 动画 | 程序行走摆动、出场缩放、前摇提示、攻击弧、受击闪色、冲刺残影 |
| 图像与声音 | 临时程序图形及合成音效，可替换为正式素材 |
| 平台 | 已验证 Windows；未接入触屏、iOS、Steam SDK 或联网 |

尚未提供完整剧情、NPC 对话、永久解锁、正式美术、配乐、完整手柄支持或正式发行安装包。课程分支目前选择后沿该分支前进，奖励尚未按学科加权。游戏平衡与购买意愿需要人工试玩。

## 给下一轮留下反馈

试玩 10 至 15 分钟，记录三件事：哪把武器最顺手、哪种攻击最难辨认、铃声改变掩体后是否更有趣。遇到故障时保存 F3 显示的种子、当前课程和操作步骤。
