# 校园异常：2D 动作游戏

本工作区用于评估校园主题的单机 2D 动作 roguelite，参考 Hades、Soul Knight 和同类作品。

当前阶段：2026-10-08，Windows 可玩战斗原型 v0.1。已接通移动、瞄准、三把武器、冲刺、四项社团技能、敌人波次、铃声、奖励选路和 Boss 结算。
